## Stack snapshot (verified 2026-06-22)

- Go 1.26.4 (CI matrix pins `1.26`); `entgo.io/ent v0.14.6`; `modernc.org/sqlite v1.53.0` (CGO-free).
- UI: React 19 + Vite 8 + TanStack Router + Ant Design 6 + Tailwind 4 + i18next; Vitest + Testing Library + jsdom.
- Docker manager talks to `/var/run/docker.sock`; the Caddy container is created and managed by nanoku itself.

## Hard constraints (will break tests if forgotten)

- `internal/api/ui.go` `go:embed`s `internal/api/dist`. **Always** `cd ui && npm run build` before any `go test ./...`. CI does this; the `make` recipes do this; a hand-rolled `go test` does not.
- Generated ent code under `internal/db/*_query.go`, `*_create.go`, `*_update.go`, `*_delete.go`, `client.go`, `mutation.go` is generated — never hand-edit. Edit `internal/db/schema/*.go` and run `make ent-generate`.
- `NANOKU_ADMIN_PASSWORD` is required at startup (see `internal/config/config.go`). The dev default in `Makefile` is `nanoku`; the default in `docker-compose.yml` is empty and fails fast.
- `NANOKU_CADDY_AUTO_HTTPS` defaults to empty for local dev. In production, set to `true` so Caddy issues real certs.

## Routing architecture (don't break this without discussion)

In `main.go`, routing layers wrap in this order (outer to inner):
1. `CORS`
2. `apiMux` — dispatches by URL pattern
   - `POST /api/apps/{name}/trigger` (public, bearer-token verified in handler)
   - `/api/` (admin: wrapped in `BasicAuth`)
   - `/` (UI: served as-is via `api.UIHandler()`)

The trigger endpoint is registered **before** the `/api/` catch-all so it wins for matching URLs. BasicAuth applies to the inner mux only, not the trigger route, because the trigger credential is a per-app bearer token, not the admin password.

## Security surfaces

- `POST /api/apps/{name}/trigger` — public, bearer-token auth. Compare tokens with `crypto/subtle.ConstantTimeCompare` (see `internal/api/trigger.go`). Reject `401` on any mismatch; no prefix/suffix tricks.
- `/api/*` (except trigger) — HTTP Basic Auth via `api.BasicAuth(cfg.AdminUser, cfg.AdminPassword)`.
- The Docker socket — treat the host as trusted; nothing on the API surface should accept a docker-socket path from user input.

## Conventions

- Commit messages: Conventional Commits (`feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`, `ci:`). GoReleaser groups `feat`/`fix` and drops the rest from the release changelog — don't expect `docs:` to appear in the release notes.
- PR target: `main`. Releases: tag `v*` triggers `.github/workflows/release.yml` → GoReleaser.
- Generated file: `ui/src/routeTree.gen.ts` is generated by `tsr generate` after route file changes.
